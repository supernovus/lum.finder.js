# lum.finder.js

A library with a few functions meant for basic filtering basic data models.

It's not meant to be a comprehensive library, but a starting point for
your own models. It's designed primarily for arrays containing object items.

## Dependencies

Version 1.0 of this library has _zero_ runtime dependencies. It doesn't even
depend on [@lumjs/core] like most of my @lumjs libraries. That _may_ change
when version 2.0 of my core library is released, but that could be a while.

This does have a couple _development_ dependencies, but as I'm the only 
developer on the @lumjs libraries, that shouldn't affect anyone else.
